MECH AI PREMIUM WEBSITE — START HERE

FILES
- index.html: page structure and content
- style.css: visual design, responsive layout, animations, light/dark theme
- script.js: demo sensor values, charts, navigation, theme toggle
- assets/: optional folder for your images/logo

HOW TO RUN
1. Extract the ZIP file.
2. Keep index.html, style.css, and script.js in the same folder.
3. Open index.html in Chrome or Edge.
4. Internet is needed for Google Fonts and Chart.js CDN. The layout still exists offline, but charts need Chart.js to load.

IMPORTANT
- The dashboard currently uses SIMULATED DEMO DATA. It is not connected to ESP32, MQTT, Raspberry Pi, or a real AI model.
- Do not present demo values as real measurements. For a real deployment, add a backend/API, connect MQTT safely, and validate your anomaly detection and missing-data estimation.
- Update project/team/contact details in index.html before publishing.
